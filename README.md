# Agentic AI Camp — training repository

**Everything here is synthetic training data.** No real project, product, or person.

This repository is the shared evidence for the Claude exercises in the Agentic AI Camp (faculty edition). It holds the same issues twice:

- **As files** in `data/` — what you add to your Claude Project through Claude's GitHub integration.
- **As GitHub Issues** in this repository — what the instructor's live MCP demonstration reads.

## Contents

| Path | What it is |
|---|---|
| `data/engineering_delivery.json` | 26 issues (`HNW-…`): requirements, implementation, tests, reviews, blockers for one release |
| `data/program_release.json` | 26 issues (`PRG-…`): milestones, dependencies, release readiness across two releases |
| `data/leadership_portfolio.json` | 28 issues (`LDR-…`): cross-programme blockers, resource conflicts, evidence gaps |
| `scenario/feature-request.md` | The change request used in the Requirements Skill demo |

All three datasets describe the same programme from three altitudes. In the GitHub Issues, each issue keeps its key in the title (for example `[LDR-305] …`) and carries labels for its dataset, status, priority, and programme.

## Rules for the exercises

- Treat everything here as **read-only evidence**. Do not edit, label, close, or comment on issues.
- Cite the issue key (for example `HNW-417`) for every claim.
- If a field is missing, report the gap. Do not invent it.
